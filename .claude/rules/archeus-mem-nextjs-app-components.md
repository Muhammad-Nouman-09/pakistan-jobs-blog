# nextjs-app/components — React components and hooks for authentication, navigation, and job listings in a Pakistan jobs board application.
- useAuth (service) — Custom hook that provides access to authentication state and user information.
- Footer (component) — Footer component with site navigation links and application information.
- DeadlineLabel (component) — Shows job application deadline status and remaining days to apply.
- AuthContext (concept) — React context managing authentication state including user, loading status, and logout function.
